# chunk_source Fix - Production Constraint

**Date:** 2026-02-08

## Problem

Script was failing to write to production database with error:

```
new row for relation "clip_chunk_spans" violates check constraint 
"clip_chunk_spans_chunk_source_check"
```

**Root cause:** Using `chunk_source: 'gpt_regeneration_v2'` which is not an allowed value in production.

## Allowed Values

The `clip_chunk_spans` table only allows these values:
- ✅ `'llm_auto'` - Auto-generated by LLM
- ✅ `'manual_curated'` - Manually created/reviewed
- ✅ `'runtime_inferred'` - Inferred at runtime

## Fix Applied

**File:** `scripts/regenerateChunksV2.ts` (Line 668)

**BEFORE:**
```typescript
chunk_source: 'gpt_regeneration_v2',
```

**AFTER:**
```typescript
chunk_source: 'llm_auto',
```
